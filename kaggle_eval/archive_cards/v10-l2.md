- main val **0.889** (✗), new-10 9/10 (✗), bias diagnosis 12/14 (✗) ⇒ 9/12 gates
- **Why this run matters**: across the three byte-identical-config runs (v9 / S2 / L2) — main val 0.9050 / 0.8940 / 0.8890 (1.6pp swing), τ(noul) 1.03–1.19, and **B2 = 0.889 / 0.3877 / 0.6951 — a 50pp range crossing the 0.5 decision line**.
