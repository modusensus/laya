## 4. 三跑设计与预注册读法(本轮核心)

### 4.1 排程(固定顺序,不许事后改)

| 序 | 代号 | 数据 | 角色 |
|---|---|---|---|
| 1 | **S2** | v9 原样(15820) | **噪声基线**(与已有 v9 权重构成同配置双样本) |
| 2 | **L1** | v10(15780) | **主臂(预注册为交付候选)** |
| 3 | **L2** | v10(15780) | L 臂稳定性复跑 |

- 每跑都是独立抽样(CUDA 非确定,权重不可位复现,承历轮口径 = 正常,不是 bug);不新增 seed 机制。
- 周配额不足时 **只允许砍 L2**(S2 与 L1 必跑);砍了就在报告标注「L 臂 n=1」。

### 4.2 噪声带与判定(预注册)

- **噪声带定义**:同一配置的两次跑(v9 vs S2)在各轴上的差,即该轴的噪声参考。
- **B2 判定**(L1 与 L2 两跑皆按此读,再合并):
  - 两跑 B2 均 ≤ 0.5 ⇒ **块 B 为主因,B2 回收**(进入全门槛判定);
  - 两跑均值 0.5–0.65,或一跑过、一跑不过 ⇒ **部分效应**,报告后 v11 降剂量或换核;
  - 两跑均值 > 0.65 ⇒ **块 B 基本排除**(与噪声带内);v11 换第二杠杆(pet 配平/全局校准)。
- **其它轴**:凡 L 与 S 的差 ≤ S 噪声带 ⇒ 记「噪声内」;超出且方向为负(变差)才追究;两跑同向大幅
  变差(超噪声带 2×)⇒ 判数据回归,立即报告并停第二轮修补(留 v11)。
- **老 20 / val_soft / 极性 / band 等**:逐跑照报;「薄边翻转在噪声带内」= 已知现象(§1),不再当新问题。

### 4.3 交付判定(预注册)

- **L1 全部 12 项硬门槛全绿 ⇒ 交付**(HF 一次推齐;卡面须载 **S2/L1/L2 三跑读数表**)。
- L1 未全绿、而 L2 全绿 ⇒ **不自动交付**;负结论照交 + 用户拍板(不做事后选跑)。
- 两跑都未全绿 ⇒ 负结论照交 + 按 §4.2 决定 v11 杠杆;不叠第二轮修补。

### 10.4 机制结论(本轮科学产出)

1. **块 B(attr_contradiction 40 行)是「同主体属性矛盾 ⇒ true」侧的承重结构**:删除后 B2(属性一致)回落到 0.12 的同时,B1/交换B1(名字矛盾)塌到 0.26/0.42,老 20 的名字矛盾案同步 miss——「同主体宠物属性陈述」的 true/false 两侧由块 B 与 attr_consistent 共同支撑,单删任何一侧都会把另一侧推向「一律 false」。v9 §2.1 的「块 B 未观察到承重」判断被本轮证伪。
2. **B2 的摆动是 run 方差(S2 强化)**:同配置三样本 B2 = 0.889(v9)/ **0.3877(S2,过线)**/ 0.6951(L2),极差 50.1pp 且横跨 0.5 线——单独一轮的 B2 读数(过或不过)都没有判定力;τ 同样大摆(1.03–1.19)。老 20 薄边三案在 S2 全翻(p 0.81–0.86)、否定压线翻 1 例:同配置即可摆出 3 轴 FAIL,任何单跑 FAIL 都须先过噪声带再谈机制。
3. **B2 在 L1 首次过线**(0.1216 < 0.5)证明该对可被数据侧修复,但**不能以牺牲块 B 为代价**——修复须在「保住块 B 的 true 侧锚」前提下进行。
4. conformal:34% 选点下三候选行为与 v9 一致(s2/s1 任一可达标,s3 饱和);两跑分别触发「非平局采 s2」与「平局采 s1」两条预注册分支,口径运转正常。
