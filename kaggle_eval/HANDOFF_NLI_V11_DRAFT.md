| 轴 | 三样本读数 | 单跑判定的荒谬之处 |
|---|---|---|
| B2 | 0.889 / **0.3877(过)** / 0.6951 | 极差 **50.1pp 且横跨 0.5 线**——同一配置既"过"也"不过" |
| τ(noul) | 1.1233 / 1.1939 / 1.0284 | 极差 0.17 |
| 老 20 薄边族(无关补充/习惯一致/临时) | v9 翻 2 案、S2 翻 3 案、L2 全过 | 同配置即可摆出 0–3 例 FAIL |
| 主 val | 0.9050 / 0.8940 / 0.8890 | 1.6pp 摆动,压线门槛(≥0.896)时半数跑会假阴 |
| 偏置诊断 | 12/14 / **13/14** / 12/14 | 同配置差 1 例 |

**结论:旧规则「单跑全绿才交付」在方差轴上不可满足(v8–v10 三轮 24 个 FAIL 里,run 方差贡献了大部分);但纪律不放宽——把判定口径从「单跑」改成「多跑统计」,门槛数值本身不动。**

## 1. 多跑判定协议(预注册核心;执行者与复核者均不得事后修改)

### 1.1 跑数与抽样
- 每个候选配置(语料 + 配方)训练 **n=3** 独立跑(同 seed 框架 20260930、CUDA 非确定即独立样本;不新增 seed 机制)。
- 三跑**地位平等**,不得挑跑、不得用一跑替换另一跑(v10 §4.3 惯例延续)。

### 1.2 轴级判定(门槛数值全部承 v9/v10,不放宽)
| 轴 | 判定口径 |
|---|---|
| 主 val acc | **三跑全部** ≥ 0.896 |
| 新 10 / 否定 5 | 三跑全部满分 |
| val_soft ≤3 / swap 0 / 极性 ≤1 / band ≥8pp / 卫生 0/35 | 三跑全部过线 |
| conformal | 三跑的采用档(§6 沿用:复跑=重裁、选点 ≤34%、平局优先 s1)全部 ≥50% @ ≤35% |
| **偏置诊断**(方差轴) | **≥2/3 跑 ≥13/14,且 B2 三跑中位数 < 0.5**(中位数口径,允许单跑翻车) |
| **老 20**(方差轴) | **三跑中位数 = 20/20,且无任何验收案在 ≥2 跑中 miss**(同一案反复翻 = 信号而非方差) |

### 1.3 交付流程
- 协议判定通过 ⇒ HF 一次推齐(卡面载**三跑全读数表** + 同配置方差带 + 「验收 35 案与训练语料零逐句交集」句 + 新头 SHA)。
- 任一轴协议判定不过 ⇒ 负结论照交,HF 不动,不叠修补(承历轮止损线)。
